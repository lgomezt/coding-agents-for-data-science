Session 2: Context Management and Agent Skills

Continue analyzing Seattle Public Library checkouts using the monthly totals and two title-level samples in your Session 1 project. The course asks how physical and digital borrowing have changed over time and builds toward a dashboard whose results can be traced to Python code.

In this session, compare Jupyter notebooks with Python scripts, then turn repeated chart instructions into a reusable skill. You will update AGENTS.md for Python source files and compare figure outputs with and without a skill that uses Duke colors.

This tutorial follows Antigravity. You can use another agentic coding tool and adapt its controls and instruction-file locations.
