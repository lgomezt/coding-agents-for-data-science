Session 2

Continue in the same project

Complete Session 1 first. Open this guide in your browser and return to the existing Session 1 project in Antigravity. Keep Session 1 as the working folder and reuse its .venv, data, and saved work.

Review analysis.ipynb in VS Code alongside Antigravity. With the Python and Jupyter extensions enabled, use Select Kernel to choose the Session 1/.venv environment. Use Run All or a cell’s play button to execute the notebook, then save it.

Check that the project contains the completed notebook, AGENTS.md, and data/README.md. Start a new conversation in that same project and ask the agent to read the rules and data notes before continuing.

Paths in this guide are relative to Session 1. The Session 2 folder holds the guide; its data/ folder stays empty. You do not need another project, environment, or data download.
