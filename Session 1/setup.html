Session 1

Start the course project

Complete the Antigravity tutorial first. Sessions 1, 2, and 3 build one Seattle library analysis, so create the course project here and keep using it for all three sessions.

  1. In Antigravity, click the folder-plus icon, then New Project and Add Folder. Select the supplied Session 1 folder and click Create.
  2. Start a Local conversation in this project. Run the Python setup prompt from the introductory tutorial with Session 1 selected. This creates the course environment once.

The supplied folder contains the lesson pages and an empty data/ folder. Git does not track empty folders, so ask Antigravity to create data/ if it is missing after cloning. All analysis files will stay in Session 1, including .venv, analysis.ipynb, project rules, skills, and the dashboard. The Session 2 and Session 3 folders contain the later guides; you will not download data into them.

Confirm that the course project's working directory is Session 1 and its Python interpreter is inside Session 1/.venv. Show both full paths. Check that session-1-foundations.html is present. Create an empty data/ folder if it is missing; otherwise list its contents. Do not change existing files.

Ask Antigravity to download the original data

Download the student-data archive. Its files come from Seattle Open Data's Checkouts by Title. Send:

Download https://github.com/AI-for-Data-Analysis/ai-for-data-analysis.github.io/raw/refs/heads/main/files/seattle-public-library.zip into a temporary location. Inspect the archive, then place these original files directly in Session 1/data/:
- combined_checkout_totals_by_month_usageclass.csv
- digital_checkout_title_sample_balanced_250k.csv
- physical_checkout_title_sample_balanced_250k.csv
- README.md
The archive stores them under seattle-public-library/. Remove that one enclosing folder when placing the files into data/. Do not generate substitute data, alter CSV values, or overwrite existing files. Keep the source README's contents and add the archive URL and download date. Delete the temporary download after successful extraction. Report each file's size, row count, columns, and date coverage. Check that the aggregate has 501 rows and each title sample has 250,000 rows; if the archive differs, report the difference before continuing.

Review the file list and a small preview. The aggregate supports questions about total checkout volume. The title files are balanced samples, so their counts do not represent full checkout totals. Later exercises examine that distinction in detail.

Continue when the project uses its own .venv and data/ contains the three source CSVs and README. The original archive's aggregate covers April 2005 through April 2026; the samples cover 2006 to 2025. Check the downloaded files before relying on those ranges.
