# Coding Agents for Data Science

Student materials for a three-class workshop. **Only Class 1 is available today**; Classes 2 and 3 will be added later.

## Class 1 — Investigate a dataset with a coding agent

1. Download [class_01_starter.zip](./class_01_starter.zip) and unzip it.
2. Open the entire `class_01_project` folder. Read `START_HERE.md`, then complete the six points in `lab.ipynb` using any coding agent that can work with the folder. Use JupyterLab 4.1 or newer to render the Mermaid diagram.
3. Paste the exact prompts you used, inspect the inline results, and write your own analysis. Run `python checks/check_submission.py` from the project folder before submitting.
4. Zip your **completed `class_01_project` folder** and upload that single ZIP to Bloque Neón. Do not submit the unchanged starter ZIP.

Keep your coding agent inside the project folder. Do not edit the files in `data/` or include credentials in your submission.
