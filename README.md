# Coding Agents for Data Science

Start with [the Antigravity tutorial](Antigravity%20Tutorial/working-with-coding-agents.html), then follow the three sessions:

- [Session 1: Foundations](Session%201/session-1-foundations.html)
- [Session 2: Reusable skills](Session%202/session-2-reusable-skills.html)
- [Session 3: Analysis to dashboard](Session%203/session-3-analysis-to-dashboard.html)

Clone this repository, then open the HTML files in your browser. Each session has separate lesson pages with a left menu and Back/Next links. The pages work locally; you do not need a web server to read them.

```sh
git clone https://github.com/lgomezt/coding-agents-for-data-science.git
cd coding-agents-for-data-science
```

Use Antigravity for agent work and VS Code for Jupyter notebooks. Another agentic coding tool can follow the exercises with adjustments to its controls.

All activities are individual. Sessions 1, 2, and 3 continue the same Seattle Public Library analysis in the `Session 1` folder. Download the source data through the Session 1 setup prompt; the repository does not include it. Git does not preserve empty folders. After cloning, create an empty `data` folder inside each Session folder; the Session 1 setup prompt also creates its folder if needed. The introductory tutorial has its own small fictional practice dataset.

Lesson materials are adapted from [Duke's AI Accelerator](https://analytics-accelerator.colab.duke.edu/index.html) and licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
