Session 3

Continue in the same project

Complete Sessions 1 and 2 first. Open this guide in your browser and return to the existing Session 1 project in Antigravity. Keep Session 1 as the working folder and reuse its .venv, data, and saved work.

Open the same Session 1 folder in VS Code alongside Antigravity. Inspect earlier Jupyter notebooks in VS Code using the project’s .venv kernel. This session uses Python source files to prepare the dashboard data.

Check that the project contains AGENTS.md updated for Python source, data/README.md, your analysis files, and the skills created in Session 2. Start a new conversation in that same project and ask the agent to read the rules and data notes before continuing.

Paths in this guide are relative to Session 1. The Session 3 folder holds the guide; its data/ folder stays empty. You do not need another project, environment, or data download.
